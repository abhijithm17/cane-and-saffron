# Cane & Saffron

A responsive landing page for a restaurant and bar, built with plain HTML, CSS and JavaScript. No frameworks or build step.

## Features
- Full-screen hero with a spinning "open daily" seal
- Dish cards, dining room section, testimonial and polaroid-style photo gallery
- Floating red dots animation (respects `prefers-reduced-motion`)
- Table reservation form (front end only, shows a confirmation message)
- Fully responsive for phone, tablet and desktop

## Run locally
Open `index.html` in your browser.

## Deployed with GitHub Pages.
1. Push this repo to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then pick `main` and `/ (root)`.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Notes
- The form does not send data anywhere yet. Connect it to Formspree, EmailJS or your own backend.
- Replace the photos in `images/` with ones you own or have a licence to use.
